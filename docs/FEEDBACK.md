# User Feedback — Level 5

## Feedback Collection Method

Feedback is being collected directly from Preprod users who try the live demo, through three channels:

- Replies and DMs on the product's X account, [@zkallowlist](https://x.com/zkallowlist)
- Direct messages to Discord/Telegram groups where the demo link is shared
- A short DM template sent to developer/college contacts, asking for a one-line reaction plus their Preprod wallet address

Each piece of feedback is logged below with the date it was received, before being triaged into themes and turned into changes.

## What We Heard (Themes)

- **Overall experience is positive** — most respondents called out the setup/onboarding flow, wallet connection, and loading states as clean, intuitive, and "native"-feeling (#2, #9, #12, #13, #16).
- **Privacy architecture is landing with technical users** — one respondent explicitly verified on-chain that no metadata leaks through the private witness data design (#6).
- **Double-claim protection works as intended** — a user deliberately tried to resubmit the same access code and got a clear "Already Claimed" message instead of a silent failure or confusing error (#11).
- **One real bug reported:** the contract explorer link on the landing page pointed to the wrong URL pattern (#10, Zoya).
