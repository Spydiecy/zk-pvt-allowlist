# User Feedback — Level 5

## Feedback Collection Method

Feedback is being collected directly from Preprod users who try the live demo, through three channels:

- Replies and DMs on the product's X account, [@zkallowlist](https://x.com/zkallowlist)
- Direct messages to Discord/Telegram groups where the demo link is shared
- A short DM template sent to developer/college contacts, asking for a one-line reaction plus their Preprod wallet address

Each piece of feedback is logged below with the date it was received, before being triaged into themes and turned into changes.
